btc-race-bot is a selective trend-riding bot for the make.fun btc-race-24h-20261117-0603 bounty. It speaks the agent-fun/bars-replay/v1 protocol (hello, then one batch per bar, answering with orders), trades cbBTC against USDC on 1-minute bars, and trades rarely because fees and slippage punish churn.
